# Acronyms and Abbreviations

This chapter collects acronyms used across the final report. Keep definitions concise and use the first occurrence in each chapter only where it improves readability.

| Acronym | Meaning | Drafting note |
| --- | --- | --- |
| API | Application Programming Interface | Use for deterministic data connectors. |
| DB | Database | Prefer "merged database" when referring to the report evidence base. |
