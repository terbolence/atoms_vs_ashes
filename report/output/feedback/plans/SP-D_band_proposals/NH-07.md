# Phase 0.6 — Band proposal: NH-07 Volcanism

## 1. Reviewer expectation

- **#96 (Timelkam, AT)**: anchor "5.0/10". Reviewer: "Scor prea mic daca vulcanic hazard este neglijabil" — "Score too low if volcanic hazard is negligible."

Reviewer's mental model: most CEE sites have **no plausible volcanic hazard** (no Holocene volcano within 1000 km is the screening criterion). When the data confirms this, the score should be `[9,10]`, not the pass-mark `5.0`.

## 2. Current rubric (snapshot)

| Score range | Condition | Descriptor |
| --- | --- | --- |
| [9,10] | `nearest_volcano_km > 1000` | No plausible pathway. |
| [7,8] | `nearest_volcano_km >= 500` | Distant; ashfall climatology benign. |
| [5,6] | `nearest_volcano_km >= 300` | Meets project minimum (>= 300 km). |
| [3,4] | `nearest_volcano_km >= 200` | Sub-threshold; specialist study required. |
| [1,2] | `nearest_volcano_km >= 50` | Elevated risk; mitigation uncertain. |
| [0,0] | `nearest_volcano_km < 50` | E4 triggered. |

`fail_conditions`: E4 (exclude) on `< 50 km Holocene volcano OR in_pyroclastic_zone == true`.

## 3. Data sanity verdict

Phase 0.5 → `data_needs_fix_before_band_edit`. `nearest_holocene_volcano_km` is **66.5% NULL** (240 of 361 sites have no nearest-volcano populated — likely because the connector's GVP catalog query returned no Holocene volcano within its search radius, but the connector wrote NULL instead of "no volcano within radius_R").

For the 121 sites with the column populated, values range 70.98–291.97 km — meaning **every populated site is in the `[3,4]` band or worse** (because all populated values are < 300). The volcanism profile is dominated by Turkish/Greek sites near Holocene volcanoes (Kula, Erciyes, Hasandag, Nisyros, Nemrut, Karaca Dag).

## 4. Diagnosis

LL-022 silent-NULL pattern: when the GVP catalog has no Holocene volcano within the connector's max search radius (likely 500 km or 1000 km), the connector writes `nearest_volcano_km = NULL`. The rubric `[9,10]` band requires `> 1000`, which NULL fails. The rubric falls through with no match → engine pass-mark default 5.0 + quality `unscored`.

For Timelkam (AT, ~600 km from nearest Holocene volcano which is in central Italy, but the AT connector run may have searched to 500 km only and returned NULL):
- Reviewer reads "5.0/10" as "system thinks there's a volcanic hazard here", but the system intended "we couldn't find a volcano within search radius".

This is the canonical FB-LL-01 + FB-LL-02 pattern.

## 5. Proposed bands

**Three changes**: (a) treat `NULL` as confidently favorable (`> 1000 km` semantically) when the connector explicitly searched and found nothing; (b) add a connector-side requirement to write a sentinel value (e.g. `nearest_volcano_km = 9999` or `nearest_volcano_km_confidence = 'no_volcano_in_search_radius'`) so the rubric can distinguish "really no volcano" from "we didn't search"; (c) keep the E4 exclusion intact.

| Score range | Condition (PROPOSED) | Delta vs current | Descriptor |
| --- | --- | --- | --- |
| [9,10] | `nearest_volcano_km > 1000 or (nearest_volcano_km is null and nh07_search_completed == true)` | **ADD** OR-clause: NULL + connector-confirmed-search → favorable | No plausible pathway (no Holocene volcano within search radius). |
| [7,8] | `nearest_volcano_km >= 500` | unchanged | Distant; ashfall climatology benign. |
| [5,6] | `nearest_volcano_km >= 300` | unchanged | Meets project minimum (>= 300 km). |
| [3,4] | `nearest_volcano_km >= 200` | unchanged | Sub-threshold; specialist study required. |
| [1,2] | `nearest_volcano_km >= 50` | unchanged | Elevated risk; mitigation uncertain. |
| [0,0] | `nearest_volcano_km < 50` | unchanged | E4 triggered. |

`fail_conditions`: unchanged.

The new field `nh07_search_completed: bool` is added to `site_natural_hazards`. Connector backfill writes `true` for every site where the GVP query was executed and no Holocene volcano was found within 1000 km. Until backfill completes, `nh07_search_completed = false` for legacy rows, which preserves current behaviour (NULL = unscored, falls to engine pass-mark, which renderer now displays as "unscored" per SP-E).

**Alternative (lower-touch)**: skip the new field, instead trust that **any NULL** means "no volcano in search radius" and treat NULL as `> 1000` directly. Risk: a connector failure that left the column NULL for unrelated reasons would be silently treated as favorable (LL-022 false-positive symmetry). **Default-recommend the explicit sentinel field**.
