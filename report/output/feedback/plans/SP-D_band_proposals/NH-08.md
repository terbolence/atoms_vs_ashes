# Phase 0.6 — Band proposal: NH-08 Coastal flooding (storm surge, tsunami)

## 1. Reviewer expectation

- **#97 (Timelkam, AT)**: anchor "5.0/10". Reviewer: "Asi spune score 10 – nu exista coastal flooding in Austria" — "I would say score 10 — there's no coastal flooding in Austria."

Reviewer's mental model: AT is a landlocked country (no coastline). The criterion should be `[9,10]` automatic for any landlocked-country site, and certainly for any site > 50 km from a coast.

## 2. Current rubric (snapshot)

| Score range | Condition | Descriptor |
| --- | --- | --- |
| [9,10] | `coast_distance_km > 50 or elevation_m >= 50` | Non-coastal OR elevation >= 50 m AMSL. |
| [7,8] | `coast_distance_km >= 10 and storm_surge_class in ['none', 'low']` | >= 10 km from coast, low surge class. |
| [5,6] | `coast_distance_km >= 5` | 5-10 km from coast; mitigation feasible. |
| [3,4] | `coast_distance_km >= 2` | 2-5 km from coast; high surge/tsunami trace. |
| [1,2] | `coast_distance_km < 2` | In 100-yr inundation extent without defensible mitigation. |
| [0,0] | `coast_distance_km < 2 and has_remedy == false` | Indefensible coastal hazard. |

`fail_conditions`: A9 (avoidance_penalty) on `coast_distance_km < 10 AND elevation_m < 50`.

## 3. Data sanity verdict

Phase 0.5 → `data_needs_fix_before_band_edit`. `distance_to_coast_km` is **100% NULL** in `site_natural_hazards`. The connector either never populated this column or routes the same value under a different field name. **The rubric is currently scoring everything via `elevation_m >= 50` if the site is high enough, otherwise falling through to `[5,6]` pass-mark default.**

For Timelkam (AT, ~400 km from any coast, elevation ~410 m AMSL):
- `[9,10]`: requires `coast_distance_km > 50 OR elevation_m >= 50`. `coast_distance_km IS NULL`; in some engine NULL semantics `(NULL > 50)` evaluates as NULL/false. `elevation_m = 410 >= 50` → TRUE. `[9,10]` matches → 9.5.

If Timelkam reads 5.0/10 in the report, **the engine is not picking up `elevation_m`** — likely because elevation lives in the `sites` table, not `site_natural_hazards`, and the rubric's variable resolution is failing. **Verify before re-banding.**

## 4. Diagnosis

Two compounding defects:

1. **Connector defect**: `distance_to_coast_km` is 100% NULL — the connector that should populate it is missing. SP-F or a one-off backfill needed.
2. **Rubric variable-resolution defect**: `elevation_m` lives in `sites.elevation_m` not `site_natural_hazards.elevation_m`. If the rubric expression evaluator is not joining tables correctly, `elevation_m` is unresolved and the OR-clause cannot match.

Both defects need to be fixed for NH-08 to give the reviewer-expected score.

## 5. Proposed bands
