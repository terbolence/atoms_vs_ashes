# Phase 0 Scope Record

This record freezes the editorial decisions that control the report build. It is intentionally short: later chapter files should cite this decision rather than reopening the structure.

## Audience

The primary audience is policy, investment, and strategic decision-makers who need a screening-grade basis for prioritising coal-to-nuclear and thermal-plant reuse opportunities. The tone should remain regulator-aware and technically traceable, but it should not read as a licence application or detailed site characterization report.

## Reference SMR Case

Use `nuscale_voygr6` as the default reference SMR case where a single technology narrative is needed for consistent country and site descriptions. This is a narrative convention for comparability, not an endorsement, procurement recommendation, licensing conclusion, or statement that a U.S. design is available in any specific market.

## Structural Choice

The report follows the canonical table of contents in [`tableOfContents.md`](tableOfContents.md):

- Chapter 2 is **Stage 1: Site Survey**.
- Chapter 3 is **Stage 2: Site Selection**.
- Chapters 4-8 cover results, country/site profiles, recommendations, final remarks, and references.

This resolves the earlier Option A / Option B question by keeping Stage 1 and Stage 2 separate. Do not merge them into a single Part II unless the canonical ToC is changed first.

## Siting Scope

The publication scope is IAEA SSG-35 Stages 1 and 2 only. Outputs support survey, screening, comparison, ranking, and a decision to progress selected sites toward Stage 3 characterization. They do not replace Stage 3 field investigations, design-basis parameter derivation, licensing-grade environmental assessment, emergency-plan approval, or operational monitoring.
