# Override notes - NS-01 Cooling Water Availability

This override extends `05_non_safety_implementation.md` for Cooling
Water Availability. Apply in addition to the family base prompt.

## Reading depth

Spend 4-6 sentences. Cooling is the binding constraint for many
inland thermal-site reuse programmes and the criterion most often
re-litigated by host-country water regulators.

## Required raw values to cite

- Distance to cooling source (km).
- Cooling source flow (m3 / s).
- Cooling source type (river, reservoir, sea, other).
- Cooling source name.
- Water stress label (Low, Low-Medium, Medium-High, High,
  Extremely High - WRI Aqueduct convention).

## Plain-English bands (flow)

| Cooling source flow | Read for one VOYGR-6 plant |
| --- | --- |
| > 5 m3 / s | comfortable for once-through |
| 1 - 5 m3 / s | workable with cooling tower or hybrid |
| < 1 m3 / s | constrained; hybrid / dry cooling required |

## Stage 3 implications

- Comfortable flow: Stage 3 commissions a cooling-water permit
  scoping study and a low-flow / drought-frequency analysis.
- Workable flow: Stage 3 must select a cooling system (closed-loop
  vs hybrid) and quantify makeup demand.
- Constrained flow: Stage 3 must evaluate dry / hybrid cooling
  with the consequent capacity penalty and the upstream water
  abstraction permitting feasibility.
- Always state the water-stress label; "Low-Medium" already implies
  a permitting workstream, "High" implies a multi-year permitting
  campaign.

## Do not

- Quote a specific cooling system selection; that is a vendor /
  EPC decision.
- Imply that proximity alone solves the criterion; flow and stress
  are the binding variables.
