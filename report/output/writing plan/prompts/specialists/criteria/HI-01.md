# Override notes - HI-01 Aircraft Crash

This override extends `02_human_induced_hazards.md` for Aircraft
Crash. Apply in addition to the family base prompt.

## Reading depth

Spend 3-5 sentences. Aircraft crash is one of the most quoted
external-events numbers in any siting review and the one where the
"airport type" qualifier matters as much as the distance.

## Required raw values to cite

- Nearest airport (km).
- Nearest flight path (km).
- Airport count within search radius.
- Nearest airport name and type (small_airport, regional_airport,
  large_airport, military_airport).

## Plain-English bands

| Distance to nearest airport | Type | Read |
| --- | --- | --- |
| > 16 km | any | comfortably outside the NRC RG 1.78 buffer |
| 8 - 16 km | small / regional | outside the standard buffer |
| 8 - 16 km | large / military | inside the buffer; site-specific crash-frequency analysis required |
| < 8 km | any | inside the standard NRC buffer; site-specific crash-frequency analysis required |

## Stage 3 implications

- Outside the buffer: Stage 3 confirms the crash frequency from
  national civil aviation authority data.
- Inside the buffer: Stage 3 commissions a crash-frequency analysis
  (NRC NUREG-0800 SRP 3.5.1.6 framework) and an airframe-impact
  vulnerability check against the vendor's certified design.

## Do not

- Infer the crash probability from distance alone; airport movement
  count is the missing variable.
- Recommend airframe-impact engineering measures.
