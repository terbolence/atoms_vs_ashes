# Override notes - HI-06 Military Installations

This override extends `02_human_induced_hazards.md` for Military
Installations. Apply in addition to the family base prompt.

## Reading depth

Spend 3-5 sentences. Military proximity is rarely mitigable by
engineering and almost always lands as a Stage 3 stakeholder
engagement item rather than a design item.

## Required raw values to cite

- Nearest military installation (km).
- Count within search radius.
- Installation name where present.

## Plain-English bands

| Distance to nearest military | Read |
| --- | --- |
| > 10 km | outside the typical interaction zone |
| 3 - 10 km | overlapping interaction zone; stakeholder engagement required |
| < 3 km | inside immediate interaction zone; potentially exclusionary on security and airspace grounds |

## Stage 3 implications

- Outside zone: Stage 3 confirms the catalogue with the host-country
  ministry of defence.
- Inside zone: Stage 3 must initiate formal ministry-of-defence
  engagement on airspace, exclusion zone, security cordon, and
  classified-information handling. State explicitly that this is a
  governance issue, not an engineering issue.

## Do not

- Speculate on the type of military activity from name or count.
- Imply that civilian engineering measures can mitigate the
  proximity.
- Recommend any specific security countermeasure.
