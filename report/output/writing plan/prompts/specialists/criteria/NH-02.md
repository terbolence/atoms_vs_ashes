# Override notes - NH-02 Seismic Surface Rupture

This override extends `01_natural_hazards.md` for Seismic Surface
Rupture. Apply in addition to the family base prompt.

## Reading depth

Spend 3-5 sentences. Surface rupture is binary in IAEA SSR-1: a
capable fault inside the exclusionary buffer is exclusionary, and
the buffer (typically 5 km in IAEA practice, 8 km in NRC RG 4.7)
deserves explicit mention.

## Required raw values to cite

- Nearest mapped capable fault (km).
- Fault slip rate (mm / yr) where available.
- Fault name where available; the EFSM20 / ESHM13 fault catalogue is
  the usual basis.

## Plain-English bands

| Distance to capable fault | Read |
| --- | --- |
| > 25 km | comfortably outside the buffer |
| 8 - 25 km | outside the IAEA / NRC buffer; standard Stage 3 follow-up |
| 5 - 8 km | inside the NRC buffer; site-specific paleoseismic study required |
| < 5 km | inside the IAEA buffer; potentially exclusionary |

## Stage 3 implications

- Comfortable distance: Stage 3 confirms catalogue coverage with a
  national fault-mapping update.
- Buffer-edge: Stage 3 commissions a paleoseismic trenching survey
  along the closest segment.
- Inside buffer: state explicitly that the criterion is potentially
  exclusionary and requires national geological survey input before
  Stage 3 may proceed.

## Do not

- Infer fault activity from slip rate alone; the database records
  capability, not a probabilistic recurrence.
- Recommend specific fault-displacement mitigation engineering.
