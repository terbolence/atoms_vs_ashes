# Override notes - NS-02 Grid Connection

This override extends `05_non_safety_implementation.md` for Grid
Connection. Apply in addition to the family base prompt.

## Reading depth

Spend 4-6 sentences. Grid connection is the most-quoted
implementation criterion in any country with an existing thermal
fleet, because the brownfield grid corridor is one of the strongest
arguments for site reuse.

## Required raw values to cite

- Nearest substation (km).
- Nearest high-voltage line (km).
- Highest nearby line voltage (kV).
- Grid export capacity (MW).
- Substation count and HV line count within search radius.

## Plain-English bands

| Nearest HV line / substation | Voltage | Read for one VOYGR-6 plant (~ 462 MWe) |
| --- | --- | --- |
| < 1 km | >= 220 kV | strong brownfield reuse; minor reinforcement |
| < 1 km | 110 kV | comfortable distance; substation reinforcement to 220 / 400 kV likely |
| 1 - 5 km | >= 220 kV | acceptable; new spur required |
| 1 - 5 km | 110 kV | acceptable but substation upgrade required |
| > 5 km | any | constrained; new corridor and consenting workstream |

## Stage 3 implications

- Strong reuse: Stage 3 commissions a grid integration study with
  the national TSO covering N-1 contingencies and short-circuit
  capacity.
- Reinforcement-likely: Stage 3 must scope a substation upgrade
  cost and timeline.
- Constrained: Stage 3 must run a grid-corridor consenting
  workstream and a long-lead reinforcement plan.

## Do not

- Promise grid acceptance; it is the TSO's call.
- Quote a specific transmission expansion budget.
- Confuse "grid export capacity" (the modelled capacity at the
  point of interconnection) with available transfer capability.
