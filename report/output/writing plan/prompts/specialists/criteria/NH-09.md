# Override notes - NH-09 River Flooding

This override extends `01_natural_hazards.md` for River Flooding.
Apply in addition to the family base prompt.

## Reading depth

Spend 3-5 sentences. River flooding is the most common avoidance
flag for inland thermal-site reuse and the one where Stage 3
hydrology has the highest information value.

## Required raw values to cite

- Flood zone class (negligible, low, medium, high).
- Distance to nearest river (km).
- Dam-break exposure flag where present.
- Reference flood-return period the class corresponds to (typically
  100-yr or 500-yr in JRC EFAS / national flood maps).

## Plain-English bands

| Flood zone class | Read |
| --- | --- |
| negligible | site is outside the 500-yr floodplain on national maps |
| low | site is in the 500-yr but not the 100-yr floodplain |
| medium | site is in the 100-yr floodplain; engineered flood defence required |
| high | site is in the 25-yr / 50-yr floodplain; potentially exclusionary without major works |

## Stage 3 implications

- Negligible / low: Stage 3 commissions a site-specific 1D / 2D
  hydraulic model to refresh the design-basis flood (DBF) and the
  combined-event extreme.
- Medium / high: Stage 3 must scope a flood-defence engineering
  envelope, evaluate dam-break consequences if upstream
  infrastructure exists, and confirm the residual risk after
  defence.

## Do not

- Recommend a specific flood-defence design (levee height, wall
  type).
- Imply that "negligible" means the criterion is closed; combined
  flood / wind events are still a Stage 3 item.
