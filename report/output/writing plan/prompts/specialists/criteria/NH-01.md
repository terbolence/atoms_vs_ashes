# Override notes - NH-01 Seismic Ground Motion

This override extends `01_natural_hazards.md` for the Seismic Ground
Motion criterion. Apply these rules in addition to the family base
prompt.

## Reading depth

Spend up to the family ceiling (~6 sentences). PGA is the single most
quoted natural-hazard number in any IAEA siting review.

## Required raw values to cite

- PGA at 475-year return period (g) - the design-basis reference.
- PGA at 2,475-year return period (g) - the beyond-design-basis
  reference.
- Hazard model name (e.g. ESHM13, USGS NSHM, GEM Global Seismic Hazard
  Map 2018).
- Vs30 reference (m/s) - matters because the ESHM13 reference is
  rock-site (Vs30 760 m/s); soft soils amplify motion.

## Plain-English bands

| 475-yr PGA | Band |
| --- | --- |
| < 0.10 g | very low |
| 0.10 - 0.25 g | moderate |
| 0.25 - 0.50 g | high |
| > 0.50 g | very high |

## Stage 3 implications by band

- **Very low** - state that the design-basis is comfortably below the
  NuScale VOYGR-6 standard plant envelope; Stage 3 work is a local
  hazard-model refresh and a Vs30 site-specific measurement.
- **Moderate** - state that the design-basis is within the standard
  envelope but Vs30 amplification needs site-specific shear-wave
  velocity profiling and a probabilistic seismic hazard assessment
  (PSHA) update.
- **High / very high** - state that a site-specific PSHA, soil-
  structure interaction analysis, and design-spectrum check against
  the vendor's certified design-response spectrum is mandatory at
  Stage 3.

## Do not

- Quote a peak ground velocity unless the bundle has it.
- Imply NRC vs IAEA spectral acceptance equivalence.
- Recommend specific isolation or damping technologies.
