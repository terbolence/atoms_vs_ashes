Same as the cluster (HI-02, HI-04, HI-05, NH-07): connector either failing or not run. The IAEA PRIS database / NEA installations registry should populate this field but is not.

For Timelkam (AT, no nuclear installation in operation in AT — only the decommissioned Zwentendorf, never operated):
- `[9,10]`: `nearest_nuclear_km > 100` — `(NULL > 100)` is NULL/false → NO.
- All bands NO → engine pass-mark 5.0.

Reviewer: "scor prea mic" — exactly the FB-LL-01 + FB-LL-02 pattern.

## 5. Proposed bands

| Score range | Condition (PROPOSED) | Delta | Descriptor |
| --- | --- | --- | --- |
| [9,10] | `nearest_nuclear_km > 100 or (nearest_nuclear_km is null and hi08_search_completed == true)` | **ADD** sentinel | > 100 km (or no other nuclear installation in search radius). |
| [7,8] | `nearest_nuclear_km >= 50` | unchanged | 50-100 km. |
| [5,6] | `nearest_nuclear_km >= 20` | unchanged | 20-50 km. |
| [3,4] | `nearest_nuclear_km >= 5` | unchanged | 5-20 km. |
| [1,2] | `nearest_nuclear_km < 5` | unchanged | < 5 km with unresolved interface. |

New field: `hi08_search_completed: bool`. SP-F backfills via PRIS query against all 361 sites.

**Note**: HI-08 is one of the easiest connectors to backfill — the IAEA PRIS database is small (≈500 reactors globally), publicly accessible, and a one-shot crosswalk from each site coordinate to nearest reactor is < 1 hour of work.

**WARNING on the last row**: when scoring an existing nuclear site (like Cernavoda) for SMR co-location, `nearest_nuclear_km` will read 0.5 (the existing reactor on the same site). The rubric scores this as "very low" which is **wrong** for the SMR co-location use case (co-location is generally favourable for shared infrastructure). This is a known edge case from the original rubric design; the proposal does not change it but flags it.

## 7. Acceptance tests / regression

- **Anchors #108, #109, #583**: HI-08 must be in `[9,10]` (Timelkam) or `[7,8]` (Braila with Cernavoda ~150 km away) after backfill.
- **Existing-nuclear-site edge case** documented as a Phase-2 follow-up: SP-D should not change the existing-nuclear-site behavior in this proposal.
