## Unlock Analysis


Seismic: Surface Rupture (NH-02) fails because the nearest mapped capable fault is 6.76 km from the site, inside the exclusionary stand-off used by the screening method. This is a structural geological constraint unless a site-specific capable-fault review changes the underlying fault classification or distance. The site also carries avoidance concerns for nearby aviation features and grid export capacity, but those are secondary because the exclusionary fault trigger removes the site before ranking. No further site-level characterisation is justified for the current brownfield envelope unless a future fault-trenching or seismotectonic review downgrades the fault evidence or identifies a different controlled site boundary outside the stand-off area. **Recommendation: Deprecate.**
