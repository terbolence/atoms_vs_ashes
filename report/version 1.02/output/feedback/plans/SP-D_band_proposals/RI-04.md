# Phase 0.6 — Band proposal: RI-04 Population density (EPZ rings)

## 1. Reviewer expectation

- **#33 (Chapter 3.2)**: "If you cannot protect the population against exposure above the legal limits — this is an exclusionary criteria. So could be both — ranking or exclusionary."
- **#564 (RO RI-04)**: "EPZ orientative distances are for screening. The real criteria according to CNCAN are based on dose calculation for and feasibility of emergency plan implementation."

Reviewer's mental model:
- RI-04 has **two modes**: **avoidance** (default; ranking penalty for high-density EPZ) and **exclusion** (when dose-feasibility cannot be met for any plausible engineering / EPZ-size combination).
- The current rubric only encodes the avoidance mode (action: `avoidance_penalty` on A12 thresholds).
- The proper exclusion criterion is dose-feasibility, not population density per se. Density is a **proxy** for dose-feasibility at screening time.

## 2. Current rubric (snapshot)

`aggregation: min_of_sub_scores` over 4 ring sub-scores (5 km, 16 km, 25 km, 80 km). Each ring has the same band shape:

| Sub-score (e.g. ring_5km) | Score range | Condition | Descriptor |
| --- | --- | --- | --- |
| | [9,10] | `pop_density_5km < 25` | < 25 /km2. |
| | [7,8] | `pop_density_5km < 100` | 25-100. |
| | [5,6] | `pop_density_5km < 250` | 100-250. |
| | [3,4] | `pop_density_5km < 500` | 250-500. |
| | [1,2] | `pop_density_5km >= 500` | > 500. |

`fail_conditions`: A12 (avoidance_penalty) on `pop_density_5km > 500 OR pop_density_16km > 600 OR pop_density_25km > 600 OR pop_density_80km > 300`.

## 3. Data sanity verdict

Phase 0.5 → `data_needs_methodology_first`. The data itself (per-ring densities from GHSL) is correctly per-ring (LL-021 honored). The bottleneck is **methodology**: SP-C (Chapter 3 rewrite) must land the dual-mode framing before RI-04's rubric can encode it.

SP-C is **complete** (per the master plan), so this proposal can now land.

## 4. Diagnosis

The current rubric is **structurally incomplete**:

1. It has only `avoidance_penalty` — no `exclude` action even when dose-feasibility is plainly impossible (e.g. dense city centre at the EPZ boundary).
2. The pass-mark band `[5,6]` is a hard population threshold (100-250 /km2), not a dose-feasibility evaluation. A site with 240 /km2 in the inner ring may still be dose-infeasible for a 5 km EPZ; a site with 300 /km2 may still be dose-feasible if the EPZ can be drawn to favourable terrain.

The **dual-mode** framing means: the rubric retains the population-density avoidance bands (cheap proxy at screening time) **and** layers an explicit `exclude` rule on dose-feasibility outright when the EPZ-density-design combination crosses a documented threshold. This requires the rubric to carry both rule families, and the renderer to disclose which one fired.

## 5. Proposed bands

**No change to existing avoidance bands** (the current per-ring thresholds are reviewer-acceptable as proxies). **Add** an `exclude` rule for the dose-feasibility threshold per FB-LL-05 + reviewer #33 + reviewer #564.

| --- | --- | --- | --- | --- |
| ring_5km | (all unchanged) | unchanged | unchanged | (as current) |
| ring_16km | (all unchanged) | unchanged | unchanged | (as current) |
| ring_25km | (all unchanged) | unchanged | unchanged | (as current) |
| ring_80km | (all unchanged) | unchanged | unchanged | (as current) |

**`fail_conditions` change**:

| Code | Action | Condition (current) | Action (PROPOSED) | Condition (PROPOSED) |
| --- | --- | --- | --- | --- |
| A12 | avoidance_penalty | `pop_density_5km > 500 or pop_density_16km > 600 or pop_density_25km > 600 or pop_density_80km > 300` | unchanged | unchanged |
| **E_RI04** (new) | exclude | (n/a — new) | **exclude** | `pop_density_5km > 1500 or (pop_density_5km > 800 and pop_density_16km > 1200) or epz_dose_feasible == false` |

Plus a `pass_mark: 5.0` companion on E_RI04 for engine compat.

`epz_dose_feasible` is a **proposed new field** (boolean, default NULL). When NULL, the field is "not yet assessed" and only the population-density E_RI04 trigger applies. When the user / Stage-2 dose calculation lands, `epz_dose_feasible == false` triggers exclusion irrespective of density.

The chapter 3 narrative (SP-C complete) has already documented the dual-mode framing. Chapter 5 RI-04 family narrative must be updated as part of SP-G to disclose which mode fired per site.
