# Inherited Chapter File Audit for Version 1.2

## Purpose

This audit classifies inherited version 1.02 report files before version 1.2 drafting. The default rule is rewrite-on-doubt and on need where need is required if any data has changed. Many items will probably have to be completely rewritten: inherited text may serve as structural reference, but the accepted version 1.2 baseline and regenerated artefacts are the authority for claims, counts, scores, figures, country ledgers, and site evidence.

## Known Publication Risks to Check in Every Inherited File

| Risk                                                                                                         | Required check                                                                       |
| ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------ |
| Internal paths or filenames in body prose                                                                    | Remove from reader-facing text; keep audit references in preparation artefacts only. |
| Run IDs in report prose                                                                                      | Replace with reader-facing analytical-basis language.                                |
| Upstream dataset, tile, library, vendor, or connector names                                                  | Remove from published copy unless explicitly allowed by writing controls.            |
| `TODO`, `placeholder`, `specialist interpretation pending`, `AI`, `agent`, `LLM`, or prompt/process language | Must not appear in publication-ready files.                                          |
| Unicode em dash                                                                                              | Banned from reader-facing text.                                                      |
| VOYGR-12, 924 MWe, or 12-module references                                                                   | Banned outside a marked historical-error appendix; VOYGR-6 is 462 MWe.               |
| Regional sensitivity driving national/site choices                                                           | Replace with national sensitivity framing.                                           |
| Missing evidence presented as a low score                                                                    | Rewrite as "unscored / no measured basis" and route to Stage 3.                      |
| Tables or captions without denominator/cohort                                                                | Rebuild captions before acceptance.                                                  |
| Belarus in published country roster                                                                          | Remove unless user explicitly restores it.                                           |
