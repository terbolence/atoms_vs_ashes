## Key decisions

- `safe_eval` was rewritten to walk the AST and evaluate top-level `Or`
  and `And` disjuncts independently. Or: any True → True; And: all True
  → True else False (treat None / TypeError as False so the AND is
  fail-closed). This is a deliberate asymmetry (Or preserves None when no
  True, And collapses to False) so the band caller's `if matched`
  semantics behave consistently.
- HI-01 v2 was authored with the actual OurAirports `airport_type`
  vocabulary (`large_airport`, `medium_airport`, …) and retains the
  legacy aliases (`large_intl`, `commercial`, …) in the membership lists
  for back-compat with any persisted rows.
- HI-06 v2 keeps its `band_recipe` exemption in the spec because the new
  band structure (high-consequence vs other-military) does not fit a
  simple `higher_is_better` recipe. The rubric and spec deliberately
  diverge for HI-06.
- The `nearest_military_airfield_km` derivation is now sentinel-aware:
  null when HI-06 search completed and found no airfield (favourable via
  the rubric `is null` branch), absent when HI-06 did not run (unscored
  default).
- The three policy decisions (NH-11 / EP-01 / full-pass drift) were
  written as A/B/C option papers with engineering recommendations but no
  defaults committed, per the user's "leave open for directional
  decisions" choice from the planning session.

## Follow-up: scoring engine crash on first end-to-end run (`score-785705a6`)

exited with status 1 after 2 s. The traceback in

joinedload IN-list — the real cause is at the very top of the SQL.

  columns added in `042_hi01_hi06_classification_columns`.
