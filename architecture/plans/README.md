# Architecture Plan Mirror

This directory mirrors implementation plans created under `/Users/terbolence/.cursor/plans/` when the plan is part of the auditable `atoms_vs_ashes` project record.

Use the same complete plan text as the global plan file. When a plan is implemented, update the mirrored copy with status and execution notes, then sync the matching file in `audit/plans/`.
